1. Secure Database Connection (db.php)

The database connection is separated into its own file to support a modular structure and improve maintainability. This prevents duplication of connection code and allows changes to be made in a single location.

File location

/glh/config/db.php

PHP Code

<?php
// db.php - Database connection file

$host = "localhost";
$dbname = "glh";
$username = "root";
$password = "";

// Create MySQLi connection
$conn = new mysqli($host, $username, $password, $dbname);

// Check connection
if ($conn->connect_error) {
    die("Database connection failed: " . $conn->connect_error);
}
?>

2. Basic Database Test Script

A simple test script was created to confirm that the database connection was functioning correctly and that product data could be retrieved.

File location

/glh/test_products.php

PHP Code

<?php
require_once "config/db.php";

// SQL query to retrieve products
$sql = "SELECT product_id, product_name, price, stock_quantity FROM products";
$result = $conn->query($sql);

// Check if results exist
if ($result && $result->num_rows > 0) {

    echo "<h2>Product List (Test Output)</h2>";

    while ($row = $result->fetch_assoc()) {
        echo "<p>";
        echo "ID: " . $row["product_id"] . "<br>";
        echo "Name: " . $row["product_name"] . "<br>";
        echo "Price: £" . $row["price"] . "<br>";
        echo "Stock: " . $row["stock_quantity"];
        echo "</p><hr>";
    }

} else {
    echo "No products found or query failed.";
}
?>

This script verifies database connectivity and confirms that data can be retrieved and processed using PHP.

## 3️⃣ Step 2: Extend your main product SQL query

You already join `categories`. We now also join `producers`.

Find your existing SQL and **update it like this**:

### ✅ Updated SQL (key change highlighted)

```php
$sql = "
    SELECT 
        p.product_id,
        p.product_name,
        p.description,
        p.price,
        p.quantity,
        p.image_url,
        c.name AS category_name,
        pr.company_name AS producer_name
    FROM products p
    JOIN categories c ON p.category_id = c.id
    JOIN producers pr ON p.producer_id = pr.producer_id
    WHERE 1
";
```

✅ Why this matters:

*   demonstrates **relational joins**
*   supports **product traceability**
*   aligns perfectly with the GLH brief
